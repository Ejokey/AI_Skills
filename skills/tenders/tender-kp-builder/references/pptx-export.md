# Экспорт в PPTX

Инструмент — **`pptxgenjs`** (Node.js).

---

## Масштаб

Исходная вёрстка идёт в пикселях (1280×720), PPTX работает в дюймах. Коэффициент:

```js
const S = 13.333 / 1280;   // px → inches
```

13.333″ — ширина слайда 16:9 в PowerPoint. Любая координата и размер из HTML-вёрстки умножается на `S`.

Держи `S` единственным источником пересчёта — не вводи параллельно отдельный коэффициент для шрифтов или отступов, иначе элементы разъедутся между собой.

---

## Внутренние ссылки

Переходы между слайдами (оглавление, навигация) задаются так:

```js
slide.addText('Раздел 3', {
  hyperlink: { slide: 3 }
});
```

Номер — целевой слайд, нумерация с 1. При изменении количества слайдов эти номера нужно обновлять так же, как и в PDF-версии — см. чек-лист синхронизации в SKILL.md.

---

## Когда это нужно

Экспорт в PPTX — не автоматический шаг. Он делается только по явному запросу: часть тендеров требует редактируемый формат, часть принимает PDF. Не собирай PPTX «на всякий случай» — это лишний артефакт, который потом расходится с PDF-версией при правках.

Если PPTX и PDF существуют оба, при любой правке обновляются **оба**, иначе они разъезжаются.
