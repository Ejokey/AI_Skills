# Правка готовых PDF (PyMuPDF / fitz)

Когда правится уже собранный PDF, а не пересобирается из HTML. Основной инструмент — `fitz` (PyMuPDF).

---

## Замена страницы

Надёжный способ — **не** удалять и вставлять, а перекрывать:

```python
# 1. Затереть содержимое старой страницы
page.update_stream(xref, b" ")
# 2. Отрисовать новую поверх
page.show_pdf_page(rect, src_doc, src_page_number)
```

**Избегай `delete_page()` / `insert_page()`** — они сдвигают индексы страниц. После сдвига ломаются внутренние ссылки, нумерация в TOC и любые сохранённые ссылки на номера страниц. Отладка такого сдвига занимает больше времени, чем весь остальной фикс.

---

## Кириллица

**Базовые шрифты не работают.** `helv`, `hebo` и прочие Base14 не содержат кириллических глифов — вместо текста получаются пустые прямоугольники или мусор.

Используй Liberation Sans TTF:
```
/usr/share/fonts/truetype/liberation/
```

**Измерение ширины текста.** Для корректной длины кириллической строки нужен явно загруженный шрифт:

```python
font = fitz.Font(fontfile=TTF_PATH)
width = font.text_length(text, fontsize=...)
```

Без этого замена текста в футере (типичная задача — поменять номер страницы или подпись) даст неверное выравнивание: строка окажется смещённой или наедет на соседний элемент.

---

## Ссылки

**Именованные назначения (named destinations) теряются при `insert_pdf()`.** Это тихая потеря — файл собирается без ошибок, но кликабельное оглавление перестаёт работать.

Пересобирай ссылки вручную:

```python
page.insert_link({
    'kind': fitz.LINK_GOTO,
    'from': rect,
    'page': target_page_number,
})
```

После любой операции слияния или пересборки PDF — проверяй, что ссылки TOC живы.

## Извлечение изображений с прозрачностью

`extract_image()` **теряет альфа-канал**. Для декоративных элементов (блобы, подложки, фигуры с мягкими краями) это критично — вместо прозрачного фона получается чёрный или белый прямоугольник.

Правильный путь — `fitz.Pixmap` + SMask:

```python
pix = fitz.Pixmap(doc, xref)
smask = fitz.Pixmap(doc, smask_xref)
pix = fitz.Pixmap(pix, smask)   # склейка RGB + альфа → RGBA
```

Признак проблемы: элемент, который на исходном слайде «висит в воздухе», после извлечения оказывается в рамке.
