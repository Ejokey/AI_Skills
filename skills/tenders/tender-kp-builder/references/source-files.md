# Работа с исходными файлами

Тендерные комплекты приходят пачками разнородных файлов: ТЗ, приложения к извещению, формы для заполнения, квалификационный отбор, реквизиты, референсные скриншоты. Часть из них ведёт себя не так, как подсказывает расширение.

---

## Битые / нестандартные docx и pdf

Некоторые файлы с расширением `.docx` или `.pdf` **на самом деле ZIP-архивы** с нумерованными `.txt` и `.jpeg` внутри. `pypdf` и `python-docx` на них падают или возвращают пустоту.

Проверка и чтение:

```python
import zipfile
if zipfile.is_zipfile(path):
    with zipfile.ZipFile(path) as z:
        names = z.namelist()   # посмотреть, что внутри
```

Если в `namelist()` видны `1.txt`, `2.jpeg` и т.п. вместо ожидаемых `word/document.xml` или структуры PDF — это тот самый случай, читай содержимое напрямую из архива.

Не делай вывод «файл повреждён» до этой проверки.

## Кириллические имена файлов

Ломают часть Python-библиотек — ошибки при этом бывают невнятные (кодировка, «файл не найден» при существующем файле).

Рабочая практика: скопировать в `/tmp/w/` с ASCII-именем перед обработкой.

```python
shutil.copy(src, '/tmp/w/doc01.docx')
```

Обрабатывать копию, результат при необходимости переименовывать обратно.

## Excel

Инструмент — `openpyxl`.

**Объединённые ячейки.** После записи в область с merged-ячейками объединение слетает — его нужно **пересоздавать вручную** после записи. Формы квалификационного отбора и приложения к извещению почти всегда содержат объединённые шапки, так что это встречается регулярно.

**Пересчёт формул.** `openpyxl` формулы не вычисляет — записывает как текст. Для получения значений:

```
/mnt/skills/public/xlsx/scripts/recalc.py
```

Если заказчик ждёт заполненную форму с посчитанными итогами, без пересчёта он получит файл с пустыми/нулевыми итоговыми ячейками.

## Референсные скриншоты

Скриншоты в комплекте — это не иллюстрации, а **эталон вёрстки**. Пользователь сверяет результат с ними пиксельно. Если скриншот приложен к запросу на правку, он показывает целевое состояние, а не текущее — читай его именно так.
