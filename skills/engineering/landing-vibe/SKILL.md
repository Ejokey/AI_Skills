# Landing Vibe — быстрый лендинг

Опирайся на скилл `design-system` для визуала. Здесь — про структуру и процесс.

## Стек по умолчанию
- **Один файл `index.html`** с инлайн-CSS (и минимумом JS). Никаких сборщиков — открывается двойным кликом.
- Если нужен масштаб — Tailwind через CDN или чистый CSS. Спрашивай пользователя только если он сам не сказал.

## Каркас секций (сверху вниз)
1. **Hero** — крупный заголовок (выгода, не фича) + подзаголовок + одна CTA-кнопка + визуал/скрин.
2. **Проблема → Решение** — 1–2 абзаца, по-человечески.
3. **Ценности/фичи** — 3 карточки, иконка + заголовок + строка текста.
4. **Как это работает** — 3 шага.
5. **Соц. доказательство** — отзыв/логотипы/цифра (плейсхолдер, если данных нет).
6. **Финальный CTA** — повтор кнопки + короткий оффер.
7. **Футер** — контакты, ссылки, мелкий шрифт.

## Копирайтинг
- Заголовки — про результат клиента, не про твой продукт.
- Глаголы в настоящем времени, короткие фразы.
- Одна цель страницы = одно целевое действие (одна и та же CTA везде).

## Адаптив
- Mobile-first. Flex/Grid, `max-width:100%` на картинках.
- Точки перелома: 640 / 1024px. На мобиле — одна колонка.

## Процесс / живое превью
1. Собери `index.html`.
2. Локально: открой в браузере или запусти `python3 -m http.server` и открой `localhost:8000`.
   В VS Code — расширение Live Server или просто «Open with Live Server».
3. На claude.ai/code — отдавай как Artifact для мгновенного превью.
4. Итерируй: меняй по одной секции, показывай результат.

## Чек-лист
- [ ] Одна CTA, повторённая ≥2 раза.
- [ ] Hero читается за 3 секунды.
- [ ] Работает без интернета (ассеты инлайн или локальные).
- [ ] Проверено на узком экране.
