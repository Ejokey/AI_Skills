# Design System — единый визуальный язык

Применяй эти правила к ЛЮБОМУ визуальному результату, чтобы работы выглядели как одна система, а не набор случайных стилей.

## 1. Принципы
- **Одна идея на экран.** Не мешай стили. Один акцентный цвет, одна семья шрифтов.
- **Воздух важнее декора.** Щедрые отступы, крупные заголовки, спокойный фон.
- **Контраст осознанный:** размер/вес/цвет работают на иерархию, а не «для красоты».
- **Тёмная и светлая тема** — обе поддерживаются, если это веб.

## 2. Палитра (замени на свою при необходимости)
```
--bg:        #0B0B0F   (dark) / #FFFFFF (light)
--surface:   #16161D   / #F5F5F7
--text:      #ECECF1   / #16161D
--muted:     #9A9AA6   / #6B6B76
--accent:    #6C5CE7   (основной акцент — фиолетовый)
--accent-2:  #00D1B2   (вторичный — бирюзовый, для CTA/подсветки)
--border:    rgba(255,255,255,.08) / rgba(0,0,0,.08)
```
Правило: **1 фон + 1 поверхность + 1 акцент**. Вторичный акцент — точечно.

## 3. Типографика
- Заголовки: `Inter` / `SF Pro` / системный sans, вес 600–700.
- Текст: тот же sans, 400–500, `line-height: 1.6`.
- Масштаб (модульная шкала 1.25): 14 · 16 · 20 · 25 · 31 · 39 · 49 px.
- Максимум **2 размера на секцию**.

## 4. Сетка и отступы
- Базовая единица **8px**. Все отступы кратны 8 (8/16/24/32/48/64/96).
- Контентная ширина: `max-width: 1120px`, боковые поля минимум 24px (моб.) / 48px (десктоп).
- Радиусы: 12px для карточек, 8px для кнопок/полей, 999px для «пилюль».

## 5. Компоненты
- **Кнопка (primary):** фон `--accent`, текст белый, padding 12/20, радиус 8, жирность 600, лёгкий hover-подъём.
- **Карточка:** `--surface`, тонкий `--border`, радиус 12, внутренний отступ 24.
- **Тени:** мягкие и редкие — `0 8px 30px rgba(0,0,0,.12)`, только на приподнятых элементах.

## 6. Чек-лист перед выдачей
- [ ] Один акцентный цвет, не считая точечного вторичного.
- [ ] Все отступы кратны 8.
- [ ] Иерархия читается без цвета (по размеру/весу).
- [ ] Контраст текста ≥ 4.5:1.
- [ ] На мобильном ничего не уезжает по горизонтали.
