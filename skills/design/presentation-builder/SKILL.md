# Presentation Builder — презентация из текста

Опирайся на скилл `design-system` для визуала (палитра, шрифты, отступы).

## Формат вывода
- **По умолчанию — HTML на reveal.js** (один файл, открывается в браузере, легко показывать и править).
  Подключение reveal.js — через CDN; если нужен офлайн (Catalina без интернета на показе) — скачай библиотеку локально и подключи файлом.
- Если пользователь просит PPTX/Keynote — выдай **структуру слайдов** (заголовок + буллеты + заметка о визуале) для быстрого переноса, либо сгенерируй `.pptx` через `python-pptx`.

## Правила слайдов
- **Один слайд — одна мысль.** Заголовок = вывод, а не тема.
- **≤ 6 строк** или ≤ 3 буллета на слайд. Остальное — в заметки докладчика.
- Крупный текст: заголовок 40–56px, тело 24–28px.
- Чередуй типы слайдов, чтобы держать ритм: титул → тезис → данные → пример → вывод.

## Каркас дека (адаптируй под задачу)
1. Титул: тема + одна строка сути.
2. Контекст/проблема.
3. Главный тезис.
4. 2–4 слайда аргументов (по одному на слайд).
5. Пример/демо/данные (график — по скиллу `dataviz`, если он есть).
6. Вывод + следующий шаг (CTA).

## Данные и графики
- Для любых чисел — простой понятный график, а не таблица. Один график на слайд.
- Подпись = вывод («Выручка выросла в 2×»), а не «График 1».

## Процесс
1. Собери структуру (заголовки всех слайдов) → покажи пользователю на утверждение.
2. Наполни контентом.
3. Собери HTML/reveal.js → превью в браузере (или Artifact на claude.ai/code).

## Чек-лист
- [ ] Каждый заголовок — законченная мысль.
- [ ] Нет слайдов со «стеной текста».
- [ ] Единый стиль (один скилл `design-system` на весь дек).
- [ ] Есть финальный слайд с призывом/итогом.
