# Полноценная среда для работы с Claude на старом iMac (macOS Catalina 10.15.8)

> Железо: **iMac 21.5", Late 2013 (iMac14,1)** · Intel Core i5 2,9 ГГц · 8 ГБ 1600 МГц DDR3 · NVIDIA GT 750M · macOS Catalina 10.15.8

## TL;DR — что делать

У тебя два пути. Они не взаимоисключающие: можно начать с Пути B (быстро, ничего не ломаем), а Путь A сделать позже.

| | **Путь A — обновить ОС (рекомендую)** | **Путь B — остаться на Catalina** |
|---|---|---|
| Суть | Через **OpenCore Legacy Patcher** ставим macOS Sonoma/Sequoia на неподдерживаемый iMac | Ничего не трогаем в ОС, работаем через Claude Code CLI (в терминале / веб) |
| Что открывается | **Всё**: десктопный Claude, свежий VS Code + расширение Claude Code, скиллы, MCP, репозитории | Claude Code CLI (текстовый режим) + claude.ai/code (веб) — **без графического расширения VS Code**, оно требует VS Code 1.98+, которого на Catalina нет |
| Риск/сложность | Средняя (разовая переустановка, ~1–2 часа, нужна флешка) | Низкая (30 минут) |
| Десктопный Claude.app | ✅ работает | ❌ не работает (нужен macOS 11+) |

**Мой совет:** сделай Путь B сегодня (заработаешь за полчаса), а на выходных — Путь A, чтобы получить действительно современный уровень и десктопное приложение.

---

## Почему десктопный Claude не ставится

Десктопное приложение **Claude.app требует macOS 11 Big Sur или новее**. Catalina — это 10.15, на поколение старше. Поэтому именно приложение поставить нельзя. Но **это не значит, что ты теряешь функционал** — скиллы, работа с файлами, репозитории, пуши, MCP — всё это живёт в **Claude Code** (CLI + расширение для VS Code), а он умеет работать и на Catalina, и уж точно на обновлённой ОС.

## Путь A — обновить macOS через OpenCore Legacy Patcher (рекомендуется)

Твой **iMac14,1** входит в список моделей, поддерживаемых OpenCore Legacy Patcher (OCLP). На него можно поставить **macOS Sonoma (14)** и даже раннюю **Sequoia (15)**. Это снимает вообще все ограничения: ставится десктопный Claude, свежий VS Code, свежий Claude Code.

**Важно про железо:**
- 8 ГБ RAM — это ОК для установки (ограничение OCLP — на моделях с 2 ГБ). Но 8 ГБ маловато для комфорта: **добавь память до 16 ГБ** (в iMac 21.5" 2013 память впаяна? — нет, у Late 2013 21.5" память НЕ обслуживается пользователем без разборки, но апгрейд возможен в сервисе). Это самый выгодный апгрейд для этой машины.
- **Обязательно поставь SSD**, если ещё стоит HDD — на Sonoma со старым HDD будет медленно. У тебя судя по «Macintosh SSD» уже SSD — отлично.
- Рекомендую целиться в **Sonoma**, а не Sequoia: на этой машине Sonoma стабильнее.

**План (кратко):**
1. Сделай **резервную копию Time Machine** — обязательно.
2. Скачай приложение **OpenCore-Legacy-Patcher** (GUI) — [dortania.github.io/OpenCore-Legacy-Patcher](https://dortania.github.io/OpenCore-Legacy-Patcher/).
3. В OCLP: *Create macOS Installer* → скачать Sonoma → записать на флешку (16 ГБ+).
4. *Build and Install OpenCore* → на ту же флешку.
5. Загрузиться с флешки (зажать ⌥ при старте), поставить macOS.
6. После установки — снова открыть OCLP → *Post-Install Root Patch* (ставит патчи под графику GT 750M).
7. Готово → ставишь **десктопный Claude.app** и работаешь как на новой машине.

Подробная официальная инструкция: [OCLP — Installation](https://dortania.github.io/OpenCore-Legacy-Patcher/START.html).

> После этого пути все разделы ниже (Claude Code, скиллы, MCP) тоже работают — просто без версионных ограничений.

## Путь B — остаться на Catalina и собрать «почти современную» среду

Здесь ядро связки: **Claude Code CLI** + **VS Code 1.97** + **расширение Claude Code**. Этого достаточно для всех твоих задач: презентации, вайб-кодинг лендингов, брейншторм, скрипты — и, главное, для **скиллов, локальных файлов, репозиториев и пушей**.

### Шаг 1. Homebrew (менеджер пакетов)

Свежий Homebrew официально требует новую ОС, но на Catalina работает через установку из исходников. В Терминале:

```bash
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

Если ругается на версию ОС — не страшно, Homebrew поставится, часть формул будет собираться из исходников (нужен Xcode Command Line Tools, он предложит установиться сам).

### Шаг 2. Node.js 18 (последняя версия для Catalina)

**Node.js 18 — последняя ветка, официально поддерживающая macOS 10.15.** Node 19+ требует новее ОС. Ставим через `nvm`, чтобы не воевать с системой:

```bash
curl -o- https://raw.githubusercontent.com/nvm-sh/nvm/v0.40.1/install.sh | bash
# перезапусти терминал
nvm install 18
nvm alias default 18
node -v   # должно показать v18.x
```

### Шаг 3. Claude Code CLI

Claude Code официально указывает минимум **macOS 10.15+**, так что Catalina формально проходит. Два способа:

**Способ 1 — через npm (рекомендую на Catalina):**
```bash
npm install -g @anthropic-ai/claude-code
claude --version
claude   # первый запуск попросит войти в аккаунт
```
> На Node 18 npm может напечатать предупреждение `EBADENGINE` (пакет «хочет» Node 22+). Это **не ошибка** — установка завершится, потому что claude работает как отдельный нативный бинарник, а не через твой Node.

**Способ 2 — нативный установщик:**
```bash
curl -fsSL https://claude.ai/install.sh | bash
```

**⚠️ Возможный подводный камень.** Свежие сборки Claude Code — это нативный бинарник, и часть источников указывает, что новейшие версии тянут минимум **macOS 13**. Если после установки `claude` не запускается (падает/«killed»), есть три обходных пути:
1. **Запусти Claude Code через npm-версию** (она чаще совместима) и/или **зафиксируй более старую версию**:
   ```bash
   npm install -g @anthropic-ai/claude-code@<older-version>
   ```
2. **Claude Code на вебе** — [claude.ai/code](https://claude.ai/code): полноценная работа с репозиториями, скиллами и пушами в облачном окружении прямо из браузера. Отлично работает на Catalina, потому что всё исполняется в облаке (эта сессия — как раз пример такого окружения). Это **самый надёжный фолбэк**, если локальный бинарник капризничает.
3. Вернуться к **Пути A** (обновить ОС) — снимает вопрос полностью.

### Шаг 4. VS Code 1.97 — но без официального расширения Claude Code

**Важная поправка.** Расширение Claude Code официально требует **VS Code 1.98.0 или новее** ([офиц. доки](https://code.claude.com/docs/en/vs-code#troubleshooting)). А **VS Code 1.97 — последняя версия, которая вообще запускается на macOS 10.15**. То есть на Catalina версии не пересекаются: **графическое расширение Claude Code в VS Code на этой машине не заработает** — либо VS Code не откроется (1.98+ на Catalina), либо расширение откажется активироваться (на 1.97).

Это меняет расклад для Пути B. Рабочие варианты:

1. **Claude Code CLI в терминале VS Code 1.97** (без расширения). Ставишь VS Code 1.97 как обычный редактор + текстовый терминал внизу, там же запускаешь `claude`. Diff-просмотра «в один клик» не будет, но весь функционал CLI (скиллы, файлы, git, MCP) доступен полностью — просто через текстовый интерфейс вместо графической панели.
   Скачай именно 1.97 (не последнюю!) — [release notes v1.97](https://code.visualstudio.com/updates/v1_97) / архив старых сборок. После установки **отключи автообновление**, чтобы VS Code не обновился до несовместимой версии:
   `Settings → "update.mode" → manual` (или `none`).
2. **Claude Code CLI в любом другом редакторе/просто в Терминале** — расширение необязательно в принципе, если тебе не критична IDE-интеграция (диффы в отдельной панели, шаринг диагностик редактора). `claude` полностью работает как самостоятельный CLI без VS Code вообще — открывай файлы в любом текстовом редакторе параллельно.
3. **claude.ai/code (веб)** — здесь ограничение версии VS Code вообще не действует, потому что всё выполняется в облаке в браузере. На практике это самый комфортный вариант для Catalina: полноценный интерфейс, скиллы, репозитории, пуши — без плясок с версиями.

**Итого для Catalina:** графической связки VS Code + расширение не будет — либо CLI в терминале (1 и 2), либо веб-интерфейс (3, рекомендую как основной). Полноценное расширение с diff-панелью получится только после Пути A (обновление ОС до Sonoma/Sequoia, где можно ставить актуальный VS Code 1.98+).

### Шаг 5. Git и работа с репозиториями/пушами

```bash
brew install git       # или уже есть в Command Line Tools
git config --global user.name "Твоё Имя"
git config --global user.email "sayasfgalalraeq@hotmail.com"
```
Для пушей на GitHub удобнее всего — **GitHub CLI** или SSH-ключ:
```bash
brew install gh
gh auth login          # авторизация в GitHub, дальше git push работает из коробки
```
Теперь Claude Code (и в терминале, и в VS Code) может делать коммиты и пуши из твоих локальных данных.

## Что получится под твои задачи

| Задача | Как решается |

| **Создание презентаций** | Скилл `presentation-builder` (см. `/skills`) → Claude генерирует HTML/Reveal.js или PPTX-структуру. На вебе — ещё и Artifacts. |

| **Единый набор скиллов везде** | Скиллы в `~/.claude/skills/` подхватываются во всех проектах. См. `skills/README.md`. |
