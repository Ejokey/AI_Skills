# AIR — опыт применения ИИ

Презентация под тендерное требование: практический опыт применения ИИ для генерации
контента, аналитики и автоматизации коммуникаций, включая настройку ИИ-ассистента /
AI-агента, подтверждённый кейсами.

Юрлицо — **AIR / ООО «КСИИ»**. 6 слайдов, 1280×720.

## Файлы

| Файл | Что это |
|---|---|
| `AIR_опыт_применения_ИИ.pdf` | Итоговый файл, его и отправляем |
| `deck/deck.html` | Собранная колода |

| `deck/shots/` | PNG по слайдам, для быстрой проверки вёрстки |
| `deck/overflow-report.json` | Отчёт о переполнении по слайдам |

## Как пересобрать

Скрипты сборки лежат **не здесь**, а в `_deckbuild/` в корне репозитория.

Причина: шелл в этой среде блокирует пути с кириллицей — кодировка искажается в проверке
прав, и путь не сопоставляется с разрешённой папкой. Поэтому командная строка держится на
латинице, а Node внутри уже свободно пишет в кириллические папки.

```
node _deckbuild/prep.js     # ассеты + CSS исходной деки + img.json
node _deckbuild/build.js    # -> deck/deck.html
node _deckbuild/render.js   # -> PDF, PNG по слайдам, отчёт о переполнении
```

`prep.js` достаточно прогнать один раз.

## Решения по содержанию

- Три кейса из четырёх — под NDA, названия абстрактные, логотипы клиентов не ставятся.
- Метрика телекома «20 → 5 сотрудников» оставлена в формулировке из деки Отто Бокк
  («остальные переведены на другие направления») — ради единообразия между колодами.
- По кейсу коммерческой недвижимости числовых метрик нет, плитки качественные.
