## Справочно

- Лимиты после регистрации: 100 запросов/юзер/день по умолчанию, до 500 юзеров (потолок 50 000/день, минимум 5000/день).
- API Terms and Conditions (с 23.10.2025): бесплатно, коммерческое использование разрешено, единственное содержательное требование — атрибуция Garmin, если показываются данные с гарминовских устройств (поле `device_name`). Право — законы ЮАР.
