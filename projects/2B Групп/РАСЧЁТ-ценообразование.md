## Подписочная модель (решение 18.08 — ставим в КП вместо разовой цены)

Методика не даёт формулы для подписки на кастомную разработку — только для сопровождения
после запуска (от 105 000 ₽/мес, 12 ч включено, сверх — 10 000 ₽/ч). Схема ниже — моя
надстройка поверх готового расчёта труда, не из документа. Логика: разовым платежом
(setup) берём только труд по грейдам (он уже включает полную себестоимость с маржой —
методика: «в ставках уже сидит всё»); надбавки, риск, инференс и онбординг размазываем
в подписку по документированному тарифу сопровождения.

**18.08, уточнение:** в КП идут только подписочные суммы, без разовых. Технически setup
никуда не делся — труд нужно оплатить кем-то. Решение: **весь truд+надбавки+риск+инференс+
онбординг размазаны в подписку на 12 месяцев** (не только слой надбавок, как в первой
версии). Это меняет месячную цифру — она теперь полностью покрывает проект, а не только
верхний слой поверх отдельно оплаченного разового платежа.

```
Месячная цена = Полная цена уровня (труд+надбавки+риск+инф+онб) / 12 мес
```

12 месяцев — не из методики, моё решение: круглый срок, совпадает с «годовая предоплата»
из раздела 6 методики (можно предложить −10% за предоплату года вперёд).

**18.08, вторая правка:** структура изменена — вместо трёх комбинированных тарифов
**два продукта по три уровня каждый**. Цены снижены по указанию человека до ориентира
150 / 250 / 350 тыс ₽/мес. Ниже — обратный вывод часов из этих цен по формуле методики,
чтобы цена оставалась защищаемой, а не назначенной.

### Как выведены уровни

Формула методики: `Цена = Труд × (1 + надбавки) × риск + инференс×2 + онбординг`.
Месячная цена = полная цена / 12 мес.

**Средний уровень каждого продукта = полный скоуп по методике** (те самые 212 ч у RAG
и 179 ч у SHADO из расчёта выше). База — урезанный скоуп, премиум — расширенный.
Это и есть обоснование: не «скидка», а другой объём работ.

### НДС

**AIR / ООО «КСИИ» — резидент «Сколково», НДС не облагается** (ст. 145.1 НК РФ).
В КП пишем «НДС не облагается», а не «кроме того НДС» — формулировка методики про
«X ₽, кроме того НДС» относится к юрлицам на общей системе, не к этому случаю.

**Сложная интеграция** (закрытая система, СЭД без открытого API, самописное ПО):

(legacy +25% + новый домен +15%) × 1,25 риск = 1 008 875 ₽ → **от 900 000 ₽**

Точная цена — после того как узнаем, что за системы у 2B Групп.

### Риски схемы (не из методики, отмечаю сам)
