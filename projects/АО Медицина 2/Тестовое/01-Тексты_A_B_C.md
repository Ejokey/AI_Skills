1. **Протокол реабилитации.** На текущей странице нет графика восстановления по неделям. Если он есть у клиники — блок «Реабилитация» расширяется во всех трёх версиях. Пока написан короткий текст без заявленных сроков.
2. **Содержание чек-листа для версии C.** Состав из 7 пунктов собран из фактуры сайта. Требуется подтверждение профильного врача, прежде чем документ уйдёт пациентам.
3. **Отзывы.** Во всех прототипах стоят демонстрационные тексты. Нужны реальные отзывы с письменным согласием пациентов и фото.
4. **Фото врачей** — в прототипы подставлены реальные фотографии с сайта клиники. Требуется подтверждение, что их можно использовать на новых страницах. Копию лицензии для блока доверия предоставляет Заказчик.
5. **Снимки «до / после».** Взяты с текущей страницы medicina.ru. Для размещения нужно письменное согласие пациента. Если его нет — блок убирается или снимки заменяются обезличенной схемой.
6. **Фоновое фото первого экрана** — во всех шести прототипах место зарезервировано, файла нет. Без него первый экран читается как незавершённый.
7. **Куда уходят заявки** из форм версий B и C — в МИС, CRM или на почту. От этого зависит объём этапа 6 сметы.
8. **Сроки ожидания по ОМС** — в текстах прототипа намеренно не указаны, потому что меняются.
