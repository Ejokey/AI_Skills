Schema validation
¶
input_schema
валидируется через
jsonschema.Draft202012Validator
до вызова executor'а. Невалидные аргументы приводят к
ToolValidationError
, эмиссии
tool.error
, executor не вызывается.
Это позволяет внутри executor'а использовать
assert isinstance(...)
без runtime проверок — schema гарантирует тип.
