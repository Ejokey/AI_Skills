AgenticOS Cookbook
¶
Production-grade операционная среда для AI-агентов. Brain (LLM + harness), Hands (sandbox с инструментами) и Session (event-sourced журнал) — три независимо виртуализируемых компонента с явными контрактами. Целевая планка — Anthropic Managed Agents, LangGraph Platform, E2B: kernel-level изоляция, vault-proxy для секретов, replay-готовность, identity-bound persistent memory.

Архитектурные дифференциаторы
¶
Brain / Hands / Session
Три компонента с явными контрактами
execute / emit+get / wake
. Brain не имеет прямого доступа к credentials. Session переживает сбой Brain. Hands изолированы. Компрометация одного компонента не распространяется на остальные.
ADR-0004, ADR-0033, ADR-0040
Event-sourced session
Append-only журнал событий. Состояние = свёртка над журналом. Метод
wake(session_id)
восстанавливает любого worker'а. Метод
replay_session()
воспроизводит сессию с другой моделью.
ADR-0004, ADR-0016, ADR-0032
Labeled untrusted content
Tool output с trust_level untrusted доставляется P-LLM с разметкой
<untrusted_data>
, а не auto-redact'ом. Соответствует production-практике Anthropic, OpenAI, Google 2026. Opt-in Q-LLM (QuarantinedLLM) сохраняется для structured extraction.
ADR-0076 supersedes ADR-0021
Identity-bound persistent agent
JWT delegation chain (RFC 8693) сопровождает каждый tool call. Memory привязана к agent_id, сессии — представления. Multi-hop delegation, JTI revocation для kill-switch.
ADR-0011, ADR-0013, ADR-0051, ADR-0088
Deny-by-default
Сеть — egress allowlist через mitmproxy sidecar. Файловая система — workspace-only. Команды — explicit allowlist. Tools — policy gate с plan-only режимом. Vault недоступен в LLM-контексте.
ADR-0020, ADR-0026, ADR-0040, ADR-0089
Three-tier memory
Core blocks (всегда в system prompt), archival (BM25 + pgvector cosine, RRF fusion), cross-session recall. Multimodal embeddings через Gemini gemini-embedding-2 — текст, изображения, аудио в одном векторном пространстве.
ADR-0010, ADR-0011, ADR-0035, ADR-0093
Curated public API
Top-level
agenticos
— только production canon и абстрактные Protocols (124 имени). Dev/test helpers (MockLLMProvider, InMemoryVault, InProcessBackend) изолированы в явном subpackage
agenticos.testing
.
ADR-0084
Thin harness
Explicit planning DAG не строится поверх reasoning-моделей. Используются
reasoning_effort="high"
, prompt caching и principle-based prompts. Эмпирическая валидация: 85.7% Pass¹ на τ²-retail с mid-tier Gemini 3.5 Flash — паритет с Sonnet 4.5 reference.
ADR-0083, ADR-0080..0082

Production-зрелость
¶
Версия v2.1 feature-complete: 0 P0 + 0 P1 элементов в реестре технического долга.
Kernel-level изоляция:
gVisor backend (
runsc
), worker pool с per-call recycle (ADR-0095). Firecracker — открытый roadmap.
Network-boundary credential injection:
mitmproxy sidecar (ADR-0040 + 0047). Credentials не доступны в LLM-контексте; токены инжектируются на уровне TLS termination.
Centralised vault:
HashiCorp Vault / OpenBao с KV v2, AppRole/K8s auth, TTL cache, active invalidate push при rotation (ADR-0041, 0091).
Three-tier memory:
SQLite+FTS5 (dev) или Postgres+pgvector (prod) с hybrid retrieval BM25 × cosine (ADR-0035). Multimodal embeddings через Gemini.
Identity и policy:
JWT delegation chains RFC 8693, multi-hop (ADR-0051), JTI revocation (ADR-0088), policy DSL с deny-by-default и plan-only mode.
Cumulative budget protection:
per-agent и per-enduser rolling windows с USD и token tracking, denial-of-wallet защита (ADR-0090).
Eval pipeline:
Inspect AI (SWE-bench, GAIA), Promptfoo, OdysseyBench, BitGN ECOM (ADR-0031, 0043, 0067, 0049), Pass^k multi-seed (ADR-0092).
Multi-agent:
supervisor pattern с
delegate
и
submit_result
, multi-hop delegation chain, subtree cost aggregation (ADR-0050–0053).
Kubernetes:
Helm chart с production safety guards (ADR-0048, 0089), multi-tenant Postgres RLS (ADR-0096), webhook transport (ADR-0097).
Frontier-aligned:
reasoning_effort
+ prompt caching + thin-harness pivot (ADR-0083). Эмпирическая Pass¹ — 85.7% на τ²-retail с mid-tier model.
