Harness loop
¶
Метод
handle_user_message(session_id, content)
выполняет один turn:
sequenceDiagram
    participant C as Caller
    participant H as Harness
    participant S as SessionStore
    participant M as MemoryManager
    participant L as LLMProvider
    participant T as ToolManager
    participant P as PolicyEngine

    C->>H: handle_user_message(session_id, "...")
    H->>H: verify delegation (idempotent)
    H->>S: emit message.user
    loop until final or max_iterations
        H->>M: fetch core blocks
        H->>S: get_events (reduce → messages)
        H->>S: emit model.called
        H->>L: call(model_id, messages, tools=...)
        L-->>H: ModelResponse
        H->>S: emit model.responded
        H->>H: cost guard check
        alt has tool_calls
            par parallel tools (concurrent=True)
                H->>T: bind + dispatch
                T->>P: policy gate
                P-->>T: allow / PolicyDenied
                T-->>H: ToolResult / ToolError
                H->>S: emit tool.called + tool.responded/error
            end
        else final message
            H->>S: emit message.assistant
        end
    end
    H-->>C: ModelResponse
Компоненты loop'а:
reduce_events_to_messages
(
src/agenticos/brain/reduce.py
) — свёртка event log в список
Message
. Содержит labeled untrusted wrapping (ADR-0076).
Policy gate
в
ToolManager.dispatch
— first-match-wins. Default
default_safe_rules()
блокирует destructive tools в plan-only.
CostGuard.check
после
model.responded
— при превышении эмитит
budget.exceeded
и переводит сессию в
errored
.
CumulativeCostGuard
(опционально, ADR-0090 Phase B) — cross-session aggregation, эмитит
budget.cumulative_exceeded
.

Critical invariants
¶
Append-only.
API не содержит UPDATE или DELETE на events. Проверяется контракт-тестом.
Идемпотентность
event_id
.
Повторный
emit_event
с тем же
event_id
возвращает существующий sequence. Проверяется контракт-тестом.
Stateless Harness.
Per-session state не хранится в
self
.
wake()
восстанавливает контекст через
get_events
. Проверяется контракт-тестом.
No credentials в harness-graph.
Import-linter контракт:
agenticos.brain.harness
не имеет права транзитивно импортировать SDK поставщиков. Структурный инвариант — pyright, ruff, imports не позволяют его нарушить.
