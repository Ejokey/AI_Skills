replay_session
с model swap. CostGuard per-session и cumulative.

Critical invariants
¶
Spans содержат только metadata; content, credentials и secrets не помещаются в атрибуты. Проверяется контракт-тестом.
TracerProvider
setup идемпотентен — повторный вызов не создаёт дубликат.
Memory exporter для tests:
get_memory_exporter()
возвращает in-process collector,
setup_tracer(exporter="memory")
.

Aux USD из voice_synthesize и web_search (TD-022 + 023)
¶
Voice synthesis и web search имеют per-call USD, зависящий от vendor. Регистрируются через
CostGuard.record_aux_usd(amount, source="voice" | "web_search")
и аккумулируются в общий
max_usd
budget.

Critical invariants:
Replay отклоняется на active source (
SessionNotReplayableError
).
Replay создаёт новый
agent_id
, оригинал не модифицируется.
replay.started
и
replay.completed
эмитятся в новой сессии в том числе при ошибке (через
finally
).
Use cases.
Regression testing — прогон production trace через новую model version. Debugging — воспроизведение incident в isolated environment. A/B testing — сравнение моделей на идентичных turn'ах.
