Инварианты ADR-0084
¶
Top-level
agenticos
содержит production canon и абстрактные Protocols плюс Settings.
agenticos.testing
содержит все Mock и InMemory helpers; из top-level не доступны.
Каждый новый production backend поднимается в subsystem
__init__
и добавляется в top-level.
Каждый новый Mock / InMemory добавляется в
agenticos.testing
.
Проверка:
tests/unit/test_public_api_surface.py
.
