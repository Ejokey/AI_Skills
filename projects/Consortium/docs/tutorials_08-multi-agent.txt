08 · Multi-agent + delegate
¶
Supervisor pattern (ADR-0050–0053). Главный агент делегирует подзадачи sub-агентам через
delegate
tool. Sub-агент имеет собственный sub-session, собственный набор tools, собственную identity. Результат возвращается через
submit_result
.
Концепция
¶
flowchart TB
    User --> Orchestrator
    Orchestrator -->|"delegate(spec='researcher', task='...')"| R[Researcher sub-Harness<br/>tools: web_search, multimodal_read]
    Orchestrator -->|"delegate(spec='writer', task='...')"| W[Writer sub-Harness<br/>tools: file_editor, python_exec]
    R -->|"submit_result(...)"| Orchestrator
    W -->|"submit_result(...)"| Orchestrator
    Orchestrator --> User
Orchestrator не имеет direct access к tools sub-агентов; он только делегирует. Это обеспечивает:
Scoped tools per sub-agent.
Researcher не имеет
file_editor
; writer не имеет
web_search
.
Isolated workspaces.
Sub-агент работает в собственной subdirectory родительского workspace.
Subtree cost aggregation
(TD-044). Spend sub-агента записывается под orchestrator's
agent_id
.

Submit result pattern
¶
Sub-агент завершает работу вызовом
