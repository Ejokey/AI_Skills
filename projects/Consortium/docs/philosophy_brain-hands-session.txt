Brain / Hands / Session
¶
Главная архитектурная аксиома AgenticOS. Зафиксирована в
CLAUDE.md
как жёсткий инвариант №1:
Brain ≠ Hands ≠ Session. Три независимых компонента с явным контрактом
execute / emitEvent+getEvents / wake+getSession
. Никогда не сливать в один процесс.
Происхождение паттерна
¶
Anthropic 8 апреля 2026 года опубликовал статью
Scaling Managed Agents: Decoupling the brain from the hands
, документирующую эволюцию production-системы Managed Agents от монолитной архитектуры к декомпозированной. Это эталонное публичное описание паттерна.
«We virtualized the components of an agent: a session (the append-only log of everything that happened), a harness (the loop that calls Claude and routes Claude's tool calls to the relevant infrastructure), and a sandbox (an execution environment where Claude can run code and edit files).»
Тот же паттерн в академической литературе формулируется через AIOS (Mei et al., COLM 2025) как разделение application layer, LLM kernel и sandbox layer.

Brain
¶
Состав:
Harness
(
src/agenticos/brain/harness.py
) — stateless event loop. Метод
handle_user_message(session_id, content)
выполняет один turn;
wake(session_id)
восстанавливает контекст из event log.
LLMProvider
Protocol
(
src/agenticos/brain/llm.py
) — абстракция модели. Реализации:
OpenRouterProvider
(default — ADR-0007),
AnthropicProvider
(text-only — ADR-0005),
MockLLMProvider
(testing, расположен в
agenticos.testing
).
reduce_events_to_messages
(
src/agenticos/brain/reduce.py
) — свёртка event log в список
Message
для LLM. Включает labeled untrusted wrapping (ADR-0076).
PolicyEngine
— фильтрация tool calls до dispatch. Семантика deny-by-default, first-match-wins.
Hands
¶
Состав:
ToolManager
(
src/agenticos/hands/manager.py
) — registry и dispatcher. Per-turn binding через
contextvars
(ADR-0100).
SandboxBackend
Protocol
— абстракция изоляции. Реализации:
InProcessBackend
(dev, без изоляции; расположен в
agenticos.testing
),
SubprocessBackend
(ADR-0033),
PooledSubprocessBackend
(ADR-0042),
GVisorBackend
(ADR-0036),
PooledGVisorBackend
(ADR-0045).
WorkspacePath
и
WorkspaceContext
(
src/agenticos/hands/workspace.py
) — boundary enforcement. Любой путь, разрешённый через

, обязан лежать внутри

Мотивация декомпозиции
¶
Три причины, по которым coupled-архитектура неприемлема в production.
Blast radius.
Если harness работает в одном процессе с tools, успешная prompt injection в LLM получает доступ к credentials, доступным процессу. Anthropic документирует исходную проблему: «In the coupled design, any untrusted code that Claude generated was run in the same container as credentials — so a prompt injection only had to convince Claude to read its own environment.» В AgenticOS Brain (Harness + LLMProvider) изолирован в trusted-плоскости; Hands (SandboxBackend) выполняет tools в отдельном процессе через
SubprocessBackend
или в kernel-level контейнере через
GVisorBackend
. Credentials живут в vault parent-процесса; mitmproxy sidecar (ADR-0040) инжектирует их на TLS-границе.
Cold start.
В монолитной архитектуре каждая сессия требует provisioning'а полного контейнера с harness'ом до начала инференса. Anthropic измерил эффект декомпозиции: «p50 TTFT dropped roughly 60% and p95 dropped over 90%». В AgenticOS Harness — stateless Python-класс; cold start составляет миллисекунды на новой Postgres-сессии. Hands могут использовать
PooledSubprocessBackend
или
PooledGVisorBackend
(ADR-0042, 0045) для амортизации cold start'а sandbox'а.
Hands portability.
Декомпозированный brain работает с произвольным множеством hands одновременно: sandbox для кода, MCP-сервер для Slack, browser-агент для веба. Anthropic: «The harness doesn't know whether the sandbox is a container, a phone, or a Pokémon emulator.» В AgenticOS
ToolManager
агрегирует local Python executors, HTTP-based sidecars (Gotenberg, Docgen), Telegram driver, BitGN ECOM adapter в едином dispatch-интерфейсе.

Wake-семантика
¶
Метод
wake(session_id)
определяет семантику восстановления harness'а после сбоя. Состояние не хранится в
self
. Контекст сессии восстанавливается из:
Event log (
SessionStore.get_events(session_id)
).
Memory (
MemoryStore
через
MemoryManager
, привязанная к
agent_id
).
Agent record (
SessionStore.get_agent(agent_id)
).
Следствие: процесс с harness'ом может быть прерван в середине turn'а, новый процесс восстановит контекст и продолжит с точки прерывания. Идемпотентность
emit_event
гарантирует, что повторная эмиссия события с тем же
event_id
при failover не создаёт дубликата.

Запреты инварианта
¶
Из
CLAUDE.md
:
Слияние Brain и Hands запрещено. Прямой вызов
llm.call()
из tool executor — нарушение.
Отсрочка декомпозиции («потом разделим») запрещена. Brain/Hands/Session разделяются с первой строки кода. Проверяется import-linter: модуль
agenticos.brain.harness
не имеет права транзитивно импортировать SDK поставщиков LLM (anthropic, openai); они изолированы в
agenticos.brain.providers
.
Хранение per-session state в
self
Harness'а запрещено. Состояние — в SessionStore или MemoryStore.
Прямое чтение credentials в Hands запрещено. Проверяется import-linter и runtime контракт-тестом.
Гарантии инварианта
¶
Сбой одного компонента не уничтожает остальные. Brain restart — harness читает event log. Hands restart — sandbox provisioning заново. SessionStore replication — Postgres failover.
Кратный fan-out. Один Brain одновременно обращается к N sandbox'ам через delegate tool (ADR-0052), каждый с собственным workspace и identity.
Replay-готовность. Любой completed event log воспроизводится через
replay_session(source_id, new_model_id=...)
с другой моделью или системным промптом (ADR-0016).
Security boundary на уровне процесса. Prompt injection в Hands не достигает credentials в Brain.
