Ключевые свойства
¶
Identity-bound storage.
Memory привязана к
agent_id
, не к
session_id
. Новая сессия использует те же archival entries; завершение сессии не удаляет память. Agent A не видит archival entries agent B — контракт-тест.
Hybrid scoring.
final_score = bm25_score × recency_decay × √importance
. High-importance entry поднимается в ранжировании даже при среднем BM25 score.
Опциональный audit.
Параметр
session_store=...
в
MemoryManager
активирует эмиссию audit events (
memory.archived
,
memory.searched
) в session log. Без него — silent operation.
