Эмпирическое доказательство ADR-0035 фиксирует, что hybrid retrieval возвращает корректный entry без лексического пересечения query и контента.
Multimodal embeddings
¶
GoogleEmbeddingProvider
поддерживает multimodal embeddings через gemini-embedding-2:
Text passages.
Images (base64-encoded parts).
Audio snippets.
Video.
PDF.
Все типы помещаются в одно векторное пространство. Это позволяет архивировать image (например, фотография invoice) и затем выполнять поиск по text query — система находит image entry по семантическому соответствию.
