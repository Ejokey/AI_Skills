mitmproxy egress sidecar
¶
ADR-0040 + ADR-0047. Vault физически в parent-процессе. RCE в sandbox не позволяет атакующему получить credentials.

CA install enforcement (ADR-0091)
¶
Sandbox должен trust'ить ephemeral CA для TLS termination. На Helm chart init container устанавливает CA в Chromium policy / system trust store до старта agent container.
В
values.yaml
:
mitmproxy
:
caInstallRequired
:
true
# init container проверяет наличие
caInstallPath
:
/etc/ssl/certs/agenticos-mitm-ca.pem
Cross-gVisor (ADR-0046)
¶
В
PooledGVisorBackend
mitmproxy sidecar расположен на host'е, не внутри gVisor container'а. Container конфигурируется с
HTTPS_PROXY=http://host.docker.internal:18443
(Docker) или
--add-host=host.docker.internal:host-gateway
(Linux). Это паттерн «non-loopback bind».
Memory bridge (
MemoryManager
через TCP+JSON-RPC) использует тот же канал.
Audit
¶
На каждый запрос эмитируются события:
egress.credentials_injected
— host, scope_used, vault_backend, credential_metadata. Token не сохраняется.
egress.denied
— при отсутствии host'а в allowlist (Python-level check в
http_client
).
Production deployment
¶
См.
docs/k8s-deployment.md
:
Sidecar — отдельный container в Pod.
caInstallRequired=true
enforce'ит init container.
mitmproxy слушает на pod-internal address; не exposed на k8s service.
