06 · Replay сессии
¶
replay_session
повторно прогоняет completed event log через новый Harness с другой моделью. Оригинальный журнал не модифицируется (wake-семантика).

Ограничения
¶
Replay не копирует следующие компоненты state'а:
Tool calls и tool results.
Replay прогоняет только user messages. Новый Harness выполняет собственные tool calls, которые могут отличаться от исходных.
Memory state.
Новый
agent_id
означает новую memory. Для shared memory требуется
ParentScopedMemoryManager
или явное копирование.
Workspace files.
Не копируются автоматически; при необходимости — отдельный шаг копирования workspace.
Эти ограничения сознательно зафиксированы в ADR-0016 (§«Не делалось в этой Фазе»). Replay предназначен для conversational regression, не full state restoration.
