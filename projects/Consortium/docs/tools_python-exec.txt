python_exec (ADR-0073)
¶
Sandboxed Python interpreter в subprocess'е. Trust level
untrusted
(stdout может содержать adversarial),
destructive=True
,
requires_isolation=True
.
Регистрация
¶
from
agenticos.hands.tools
import
register_python_exec
count
=
register_python_exec
(
tools
)
Не работает на
InProcessBackend
без
allow_unsafe_tools=True
. Production-конфигурация —
SubprocessBackend
(Linux + Windows) или
GVisorBackend
(Linux / WSL2, kernel-level isolation).

Безопасность
¶
cwd locked на workspace.
env scrub (аналогично
bash
).
Network deny by default —
GVisorBackend
с
--network=none
.
No persistent state (TD-057 — persistent Python session — open P2).
Output cap — 256 KiB.
Timeout cap — 600 секунд.
Применение
¶
Math и data manipulation в изолированной среде.
Script generation моделью и его выполнение в один turn.
Sub-language для агента: модель пишет Python, наблюдает stdout, итеративно debug'ит.
