pdf_read (ADR-0065 + 0098)
¶
Extract text from PDF. Primary engine — pdfplumber, fallback — vision-LLM OCR.
{
"path"
:
"report.pdf"
,
"pages"
:
"1-3,5"
,
# опционально, default — все страницы
"ocr"
:
"auto"
|
"off"
|
"force"
,
# auto = OCR при пустом text layer
}
Output — trust level
untrusted
:
{
"text"
:
"..."
,
"page_count"
:
12
,
"ocr_pages"
:
[
3
,
5
],
"truncated"
:
false
}

pip install -e ".[ocr]"
