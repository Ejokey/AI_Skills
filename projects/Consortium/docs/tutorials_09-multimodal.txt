09 · Multimodal — изображения, аудио, видео, PDF
¶
multimodal_read
(ADR-0075, supersedes ADR-0071
image_read
) — unified понимание файла через Gemini multimodal API.
Назначение
¶
Tool принимает путь к файлу в workspace и question, возвращает текстовое описание. Поддерживаемые форматы:
Изображения:
PNG, JPEG, WebP, HEIC, HEIF, AVIF (через
vision
extra — Pillow + pillow-heif + pillow-avif-plugin transcode).
Аудио:
WAV, MP3, AAC, FLAC, OGG, OPUS.
Видео:
MP4, MOV (с extract frames).
PDF:
текст, figures, structure.
trust_level —
untrusted
. Output обрабатывается reduce-pass с обёрткой
<untrusted_data>
(ADR-0076).

HEIC и AVIF support (TD-055)
¶
iPhone и Android по умолчанию используют HEIC / HEIF для фотографий. AVIF — современный browser format. Gemini API принимает JPEG, PNG, WebP — нативные форматы транскодируются через Pillow + plugins.
pip
install
-e
".[vision]"
# Pillow + pillow-heif + pillow-avif-plugin
Функция
_transcode_to_png_if_needed
выполняет конвертацию автоматически. Alpha-канал композится на белый фон для RGB output.

Эмпирическое сравнение reduce-pass подходов
¶
ADR-0076 документирует production-инцидент. Пользователь Telegram-бота прислал фотографию коробки восковых мелков.
multimodal_read
корректно вернул:
This is a box of wax crayons. The text identifies the brand as 'Kalyaka-Malyaka'.
The box indicates 8 different colors, suitable for ages 3+.
Pre-ADR-0076 (auto-redact): модель сгенерировала hallucination — «таблица с меню для детского учреждения».
Post-ADR-0076 (labeled untrusted): модель отвечает корректно — «Это коробка восковых мелков 'Каляка-Маляка', 8 цветов, для детей от 3 лет».
Trust level и labeling
¶
multimodal_read.output_trust_level = "untrusted"
. В reduce.py содержимое оборачивается:
<untrusted_data tool_call_id="tc-1">
This is a box of wax crayons. Brand 'Kalyaka-Malyaka'. 8 colors, ages 3+.
</untrusted_data>
Модель видит контент и маркер; на уровне system prompt обучена quote и summarise, не treating instructions inside as commands. См.
Философия → Labeled untrusted
.
