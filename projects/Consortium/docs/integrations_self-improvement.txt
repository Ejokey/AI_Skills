Self-improvement loop
¶
ADR-0057. Replay production traces → judge feedback → LLM-driven AgentSpec tuning.
Схема
¶
flowchart LR
    P[Production traces<br/>session log] --> R[replay_session<br/>через current AgentSpec]
    R --> J[LLMJudge<br/>criteria-based]
    J --> A[Aggregate<br/>failures]
    A --> T[Tuning LLM<br/>generates new AgentSpec]
    T --> V[Validation<br/>eval suite]
    V -->|pass| New[New AgentSpec<br/>v2]
    V -->|regress| Loop[Iterate]

Алгоритм
¶
Replay sample sessions
через
current_spec
(текущий prompt / model / tools).
LLMJudge
оценивает каждый replay outcome против criteria.
Aggregate failures
— выявление паттернов ошибок: излишняя verbosity, пропуск tool X, hallucinated dates.
Tuning LLM
генерирует новый prompt, адаптирует tool descriptions, предлагает model swap.
Validation
— прогон new spec через held-out eval suite.
Compare
— при росте pass rate spec adopt'ится; при регрессии — итерация с предыдущим spec и новым failure pattern.
