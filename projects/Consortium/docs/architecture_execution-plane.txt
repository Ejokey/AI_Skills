Vault pre-injection (ADR-0038)
¶
В worker pool архитектуре credentials не передаются в worker напрямую. Pre-injection pattern:
Parent process запрашивает credentials из vault до spawn worker'а.
Worker process получает credentials как часть serialized work payload.
После tool dispatch credentials в worker'е zeroed-out.
Паттерн совместим с mitmproxy sidecar (ADR-0040): credentials не покидают parent process, sidecar выполняет credential injection на TLS-границе.
NDJSON event streaming (ADR-0094)
¶
В pooled backends (
PooledSubprocessBackend
,
PooledGVisorBackend
) worker эмитит события в parent в режиме streaming, не только в конце dispatch'а. Это необходимо для long-running tools (bash с progress output, browser navigation).
{"type": "tool.progress", "tool_call_id": "tc-1", "message": "..."}
{"type": "tool.partial_output", "tool_call_id": "tc-1", "delta": "..."}
{"type": "tool.finished", "tool_call_id": "tc-1", "result": "..."}
WorkerPool
имеет
on_event
callback, который forward'ит события в parent
SessionStore
. SSE subscribers (
BroadcastSessionStore
) видят события в real time.
