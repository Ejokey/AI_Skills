Шесть подсистемных страниц
¶
Control plane (Brain + Session)
Harness loop, LLMProvider abstraction, event-sourced SessionStore, reduce-pass, wake-семантика, pass-through reasoning_effort и max_tokens, опциональный PEV middleware.
ADR-0004, 0005, 0007, 0032, 0083, 0100
Execution plane (Hands)
ToolManager с per-turn binding через contextvars, четыре sandbox-tier'а, WorkspacePath boundary enforcement, NDJSON event streaming из worker'ов, vault pre-injection.
ADR-0009, 0024, 0033, 0036, 0042, 0045, 0094, 0095, 0100
Memory — three-tier
Core blocks в system prompt, archival с гибридным retrieval (BM25 + pgvector cosine, RRF fusion), cross-session recall. Multimodal embeddings через Gemini gemini-embedding-2. Identity-bound через agent_id. Sleep-time consolidation.
ADR-0010, 0011, 0034, 0035, 0058, 0074, 0093
Identity & Policy
Principal (user / agent / service), DelegationChain (RFC 8693 JWT, multi-hop), JTI revocation, PolicyEngine с deny-by-default и first-match-wins, plan-only mode, destructive flag, vault backends.
ADR-0012, 0013, 0027, 0030, 0041, 0051, 0088, 0091
Observability & Replay
OpenTelemetry + OpenInference attribute set, Langfuse self-hosted, replay_session с model swap, CostGuard per-session USD и cumulative cross-session, Pass^k methodology.
ADR-0014, 0015, 0016, 0017, 0022, 0090, 0092
Event таксономия
28+ типов событий в discriminated union: session, message, model, tool, policy, budget, replay, memory, auth, egress, quarantine. Append-only, идемпотентность по event_id.
ADR-0004

├── settings.py              # pydantic-settings BaseSettings

│   ├── harness.py           # Harness — stateless event loop
│   ├── llm.py               # LLMProvider Protocol + error hierarchy

├── session/

│   ├── sqlite_store.py      # SQLiteSessionStore
│   ├── postgres_store.py    # PostgresSessionStore + RLS

│   └── broker.py            # PubSubBroker (Redis / InMemory)
├── hands/
│   ├── manager.py           # ToolManager (contextvars binding, ADR-0100)
│   ├── workspace.py         # WorkspacePath + WorkspaceContext
│   ├── backends/            # InProcess / Subprocess / GVisor + Pooled
│   ├── tools/               # 31 встроенный tool
│   ├── proxy/               # EgressProxy + mitmproxy sidecar
│   └── workers/             # NDJSON event streaming, vault pre-injection
├── memory/

│   ├── recall.py            # RecallStore (cross-session)

├── identity/
│   ├── jwt_tokens.py        # encode / decode delegation tokens

│   ├── engine.py            # PolicyEngine (deny-by-default + first-match-wins)
│   ├── backend.py           # PolicyBackend Protocol
