Sleep-time consolidation
¶
ADR-0058 + ADR-0074. Batch-сервис, суммаризующий old archival entries в semantic clusters по cron. Episodic → semantic memory transition.
Концепция
¶
Letta-style observation: long-running агенты накапливают большое количество low-importance archival entries. Периодическая консолидация группирует related entries в высокоуровневые summary, сохраняя retrieval-quality при сокращении объёма хранилища.
flowchart LR
    A[Archival entries<br/>5000+ raw observations] --> S[Sleep-time scheduler<br/>nightly cron]
    S --> C[Cluster по semantic similarity<br/>или category]
    C --> L[LLM-driven summarisation<br/>cluster → summary entry]
    L --> N[Запись summary entries с высокой importance<br/>деактивация оригиналов]
