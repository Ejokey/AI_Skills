Active rotation push (ADR-0091)
¶
При rotation credentials на Vault сервере parent process должен явно вызвать
vault.invalidate_cache()
— следующее обращение mitmproxy sidecar перечитает credentials с сервера.
# Operator triggers rotation, then signals AgenticOS:
vault
.
invalidate_cache
()
# Следующая mitmproxy injection re-fetches from Vault
Email account store
¶
Email SMTP/IMAP passwords хранятся отдельно в
EmailAccountStore
(Keyring или InMemory):
from
agenticos.identity
import
KeyringEmailAccountStore
email_store
=
KeyringEmailAccountStore
(
config_path
=
"email-accounts.toml"
)
# Passwords в keyring под "agenticos:email_{account_id}_smtp" / "_imap"
Это не SecretsVault: SMTP/IMAP используют protocol-level auth, не HTTP header injection.
