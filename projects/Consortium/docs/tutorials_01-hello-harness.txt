01 · Hello, Harness
¶
Минимальный AgenticOS harness без API-ключей. In-memory SQLite +
MockLLMProvider
. Демонстрирует архитектурный паттерн Brain / Hands / Session и event log.
Состав примера
¶
Пять компонентов:
SQLiteSessionStore
— append-only event log.
Agent
— носитель идентичности (UUID), к которому привязаны сессии и память.
MockLLMProvider
— реализация
LLMProvider
Protocol с заготовленными ответами.
Harness
— stateless event loop.
Event log как source of truth.
sequenceDiagram
    actor User
    participant H as Harness
    participant L as MockLLMProvider
    participant S as SQLiteSessionStore

    User->>H: handle_user_message("Привет!")
    H->>S: emit message.user
    H->>S: emit model.called
    H->>L: call(messages, tools=[])
    L-->>H: ModelResponse
    H->>S: emit model.responded
    H->>S: emit message.assistant
    H-->>User: ModelResponse

Разбор компонентов
¶
SQLiteSessionStore
— append-only журнал (
ADR-0004
). Production-замена —
PostgresSessionStore
(
ADR-0032
) с идентичным контрактом. Параметр
db_path=":memory:"
создаёт SQLite в RAM (сессия теряется при exit); для persistence —
db_path="agenticos.db"
.
Agent
— носитель идентичности:
agent_id
— UUID, primary key для всего state (memory, sessions).
system_prompt
— инжектится в LLM context каждого turn'а наряду с core memory blocks.
model_id
— модель по умолчанию (overridable per call).
created_at
— UTC timestamp.
MockLLMProvider
— реализация
LLMProvider
Protocol. Возвращает заготовленные
ModelResponse
в порядке списка. Production-альтернативы:
OpenRouterProvider
— default для tool-using deployments (ADR-0007).
AnthropicProvider
— direct API, text-only (ADR-0005, 0084): попытка передать tools поднимает
LLMPermanentError
.
Harness
— stateless. Метод
handle_user_message(session_id, content)
выполняет последовательность:
Verify delegation (idempotent per session, при первом turn'е).
Emit
message.user
.
Fetch core memory blocks (если
MemoryManager
присоединён).
Reduce events → messages для LLM.
Emit
model.called
.
llm.call(model_id, messages, tools=...)
.
Emit
model.responded
.
CostGuard check.
При
tool_calls
— dispatch каждого с эмиссией
tool.called
и
tool.responded
/
tool.error
. Цикл повторяется (по умолчанию до 10 итераций).
При отсутствии
tool_calls
— emit
message.assistant
, return.
При перезапуске процесса новый
Harness
instance читает event log и продолжает с точки прерывания — wake-семантика без явного вызова
wake()
.
