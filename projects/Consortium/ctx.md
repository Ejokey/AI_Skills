## Контекст
Демо 21.08.2026 продукта SHADO (наш ИИ-консьерж; ядро — фреймворк AgenticOS) заказчику — архитектурно-проектному бюро (Василий, директор; Евгений, коммерция; Алексей, проекты). Заказчик хочет управленческую среду. Пилот ожидается на 5-6 человек.

Кратко о фреймворке AgenticOS (open-source, Python, MIT): архитектура Brain/Hands/Session, event-sourced сессии, sandbox (4 tier) + labeled untrusted, identity/policy (JWT delegation), память 3 уровней (block / archival BM25+pgvector / cross-session), 31 tool (core/web/extract/multimodal/office/rendering/python-exec/calendar-email/memory), Telegram-бот как эталонный driver. По документации: email (SMTP/IMAP, мультиаккаунты), календарь (ICS .ics), office (PDF/DOCX/XLSX), multimodal_read (понимает аудио/видео/PDF через Gemini), voice_synthesize (синтез речи). НЕТ: Google Drive tool, MAX-мессенджер, STT-таймкод расшифровки, готового UI-дашборда.

## Потребности заказчика (из транскрипта встречи)
- «Управляшка»: единое пространство, задачи/договоры/документы/статусы, «кто чем занят».
- Видеть состояние каждого проекта и сроки (не терять сроки).
- Дашборд/статусы для руководителя («кто кому передал мяч»); минимум заполнения — голосом/текстом, без жёстких таблиц.
- Связка «договор→исполнитель→суммы», поиск по исполнителю (исполнители мешаются между ГИПами).
- Интеграции: Google-хранилища («доверяем Google», 2ТБ), почта/Outlook, календарь, вероятно конкретные сервисы.
- MAX (российский мессенджер) — часть сотрудников только им пользуется.
- Разделение: рабочий чат vs общение.
- Права доступа, согласие руководителя.
- Автозвонки НЕ нужны; расшифровка переговоров/встреч — важна.
- Самообучаемость, не жёсткая система (Битрикс не зашёл), без лимитов токенов, human-in-the-loop.
- Пилот 5-6 чел, co-design, без сокращений.
