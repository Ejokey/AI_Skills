# Модели агентов — раскладка и откат

Кто на какой модели работает, почему так, и как быстро попробовать иначе.

Смотреть и менять — через скрипт, а не правкой файлов руками:

```bash
bash scripts/agent-model.sh show
```

**После любой смены — рестарт сессии Claude Code.** Frontmatter агентов читается
на старте, на лету не подхватывается.

## Что считать «работает плохо»

Смотреть на ближайших 2–3 тендерах. Признаки, по которым понижение модели не оправдалось:

- `STATUS.md` заполняется формально: паспорт с пропусками, стадии без причин пропуска
- агент выдумывает цифру вместо «нужна цифра от руководителя» — это прямое нарушение §6
  `AGENTS.md` и повод откатить немедленно, без накопления статистики
- заключение `tender-analyst` — пересказ документации вместо вывода об участии
- приходится переспрашивать и переделывать: экономия съедается лишними циклами

Один промах — не повод откатывать. Систематическое — повод.

## Лестница отката

Ступени идут от самого дешёвого действия к самому дорогому. Спускаться по одной.

**1. Вернуть одного агента на модель сессии** — если проблема у конкретной стадии:

```bash
bash scripts/agent-model.sh reset tender-estimate
```

**2. Промежуточная ступень — `sonnet`** — если haiku не тянет, а полная модель избыточна:

```bash
bash scripts/agent-model.sh set sonnet tender-analyst
```

**3. Полный откат к тому, что было** — убирает поле `model` у всех агентов:

```bash
bash scripts/agent-model.sh reset --all
```

**4. Откат через git**, если что-то пошло не так со скриптом:

```bash
git checkout -- .claude/agents/
```

## Чего здесь сделать нельзя

Поле `model` принимает **только модели Anthropic**: `haiku`, `sonnet`, `opus`, `inherit`.
Написать `deepseek-v4-flash` или `gpt-5.6-luna` не выйдет — Claude Code не умеет
роутить агента в сторонний провайдер, ни через frontmatter, ни через настройки.

Сторонние модели с `opencode-go` доступны через `hermes` — отдельный CLI, ключ уже
прописан в его `.env`. Паттерн вызова для vision-задач зафиксирован в `memory/rules.md`.

## Вариант B: Hermes как MCP-инструмент — тупик, не работает как задумано

**Проверено 2026-08-10.** `hermes mcp serve` не даёт доступ к текстовым моделям — это
мессенджер-мост (Telegram/Discord/Slack и т.п.: `conversations_list`, `messages_send`
и подобное), инструмент для работы с чужой перепиской, а не для делегирования анализа.
Подключать его агентам тендерного пайплайна незачем и небезопасно (`messages_send` —
реальная отправка сообщений в подключённые каналы). `.mcp.json` создавался и удалён
в этом же сеансе, в репозитории не остался.

## Вариант A: Bash-обёртка `hermes -z` — рабочий, подтверждён на реальном сбое

**Проверено 2026-08-10**, тендер 17055043. Команда:

```bash
hermes -z "<задача>" -t file -m deepseek-v4-flash --provider opencode-go
```

`-z` — one-shot режим, печатает только финальный текст ответа, без баннера/спиннера.
`-t file` — тулсет для чтения локальных файлов (docx/pdf/xlsx по пути).

**Результат теста:** тот же вопрос, на котором `tender-analyst` на haiku дважды
провалился (устанавливает ли документация ЭА доп. требования к участнику) — deepseek
через эту обёртку нашёл точную цитату пункта 7 с первого раза, корректно различил
обеспечение заявки/исполнения (там, где `tender-intake` на haiku их перепутал), честно
пометил два скана без текстового слоя как непрочитанные (не выдумал содержимое), и
дополнительно нашёл антидемпинговую оговорку п. 8.1, которую пропустили все — включая
оркестратора при ручной перепроверке. Подробности — `tenders/Аукцион 223-ФЗ — сайт
17055043/STATUS.md`, лог за 10.08.

**Статус:** внедрено 2026-08-10 как инструмент (не замена модели) в `tender-intake`,
`tender-analyst` (получил `Bash` в `tools:`), `tender-estimate` — раздел «Инструмент:
Hermes для тяжёлого чтения» в каждом. Агент сам решает, когда позвать `hermes -z` для
вычитки длинного документа, и обязан пометить в отчёте, что взял через него, а что
прочитал сам — это даёт оркестратору материал для сравнения качества по мере накопления
прогонов. Один подтверждённый случай пока не статистика — оцениваем на следующих
тендерах, тем же порядком, что и переключение на haiku.
