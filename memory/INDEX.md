# Память — оглавление

Точка входа в память системы. Открывай отсюда только те файлы, которые нужны задаче.

| Файл | Что внутри | Читать когда |
|---|---|---|
| [company.md](company.md) | Юрлица, контакты, портфолио, бренды | Любой клиентский документ, КП, заявка |
| [pricing.md](pricing.md) | Параметры ценообразования, ставки, ориентиры по объёмам | Смета, НМЦ, прикидка стоимости |
| [rules.md](rules.md) | Накопленные правила работы, применимые ко всем проектам | Всегда, до начала работы |
| [log.md](log.md) | Датированный лог решений и изменений | Когда надо понять, почему что-то устроено так |

Контекст по конкретному клиенту — не здесь, а в `projects/<Клиент>/CONTEXT.md`.

---

## Правила работы с памятью

Полный протокол — в `AGENTS.md`, §6. Кратко:

- Пишем то, что будет важно **через 3 месяца на другом проекте**.
- Одна запись = один факт. Дата абсолютная.
- Обновляем существующую запись, а не плодим дубли.
- Устаревшее удаляем, не оставляем рядом с новым.
- После записи — одна строка человеку о том, что записано.
