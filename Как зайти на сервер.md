# Как зайти на сервер (nosta)

**Сервер:** Ubuntu 24.04, IP 178.236.247.141, хостинг Timeweb.
**Что на нём:** Hermes (личный ассистент), Forecast Studio, VPN родни (wg-easy), заметки и канбан.

## Вход с этого ноутбука (Windows)

Открой **PowerShell** (Пуск → набери «powershell») и выполни:

```
ssh root@178.236.247.141
```

Ключ подхватится автоматически (C:\Users\Vladislav\.ssh\id_ed25519).
Если не подхватился — укажи явно:

```
ssh -i C:\Users\Vladislav\.ssh\id_ed25519 root@178.236.247.141
```

Пароль вводить не нужно — вход только по ключу (настроено 12.08.2026).

## Полезные команды на сервере

```
ls /root/.hermes/              # файлы Hermes
cat /root/.hermes/notes.md     # заметки
cat /root/.hermes/tasks.md     # канбан задач
systemctl status hermes-gateway   # работает ли Hermes
systemctl status forecast-studio  # работает ли Forecast Studio
systemctl status caddy            # работает ли HTTPS-прокси
```

## Что НЕ трогать

- **wg-easy** (контейнер VPN родни) — Docker-контейнер, не останавливать и не менять!
- Порты 51820/UDP (VPN) и 51821 (панель) — настроены, руками не менять.
